# Changelog

## 0.1.0 - 2026-08-30

- Initial Rust/Win32 controller and tray application.
- Separate .NET 8 SMBLibrary engine over same-user named-pipe IPC.
- IPv4/IPv6 Direct TCP listeners, IPv4 NetBIOS transport and configurable NBNS.
- Configurable ports, protocol versions, authentication, shares, ACLs and CIDR policy.
- Session monitoring/termination, bounded asynchronous logging and diagnostics.
- DPAPI-protected independent-account passwords and parent-process supervision.
- Light mode, baseline/x86-64-v3/native release profiles, Windows CI and handoff docs.
